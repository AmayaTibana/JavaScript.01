This repository serves as my personal notebook for JavaScript.

It’s a place to save my practice, revisit concepts, and keep track of the code I write throughout my learning process.

🛠️ The Approach

Learn a concept. Write some code. Test it. Make mistakes. Figure it out.

Repeat until it makes sense.

The goal isn’t to write perfect code from day one. It’s to understand a little more than yesterday.
